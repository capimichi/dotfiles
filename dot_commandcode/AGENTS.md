# Preferenze personali

## Skill personali

Le mie skill personali stanno in `$USER_SKILLS_DIR`. Prima di eseguire qualsiasi
task operativo, consulta `$USER_SKILLS_DIR/README.md` per individuare la skill
corretta e i suoi trigger, poi segui le istruzioni della skill.

Riferimenti rapidi:

- Task, to-do list, promemoria, progetti -> `ticktick/`
- Documenti, fatture, scontrini, OCR -> `paperless/`
- Campagne affiliate, report conversioni, pixel -> `worldfilia/`
- Media, film, serie TV viste, cronologia -> `nuvio/`, `trakt/`, `stremio/`
- Amazon, acquisti, ordini -> `amazon/`
- Musica, tracce, download -> `soulsync/`, `spotify/`, `lucida.to/`, `amazon-music/`
